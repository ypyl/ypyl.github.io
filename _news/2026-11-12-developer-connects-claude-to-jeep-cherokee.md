A developer posting as **zulali** has connected **Claude** to the engine computer of a 32-year-old **Jeep Cherokee** using a **$3 Arduino Nano** and a laptop, giving the model a live feed from the car. With the connection in place, Claude reads engine fault codes, tracks RPM and coolant temperature, analyzes fuel consumption and pulls raw sensor values to help diagnose problems. The hardware side runs on **xj-scanner**, an open-source scanner project for the Cherokee XJ, with the Arduino bridging the vehicle's diagnostic port to the laptop. The demo video is a working answer to the question of how little it takes to put an AI diagnostician in a 1990s car.
