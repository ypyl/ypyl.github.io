Jack Dorsey, co-founder of Twitter and Block, has introduced **Buzz** — an open-source corporate messenger where AI agents work alongside human employees as first-class participants. Built on the decentralized Nostr protocol, Buzz combines team chat, development management, and agent collaboration in a Slack-like interface with channels, threads, voice messages, file sharing, and GitHub integration. Each AI agent receives its own cryptographic account with channel access rights, enabling them to read conversations, interact with repositories, create and submit patches, review code, and coordinate other agents. Buzz supports third-party AI tools including OpenAI Codex, Claude Code, and Goose (installed separately) and is available under the Apache 2.0 license for macOS, Windows, and Linux.
